| Area | Details |
|---|---|
| **Customer Segment** | Students, young professionals and small households with a fixed monthly income |
| **Jobs to be Done / Problems** | Track spending, stay within budget, save regularly |
| **Triggers** | Money finishing before month-end, a large unexpected bill, a savings target for a purchase or trip |
| **Emotions Before** | Anxious, guilty, out of control |
| **Emotions After** | Confident, in control, motivated |
| **Available Solutions** | Notebooks, spreadsheets, generic finance apps |
| **Root Cause** | Manual, time-consuming tracking and no personal, predictive guidance |
| **Our Solution** | Pocket Smart AI automates categorisation, forecasts spending and sends timely, personalised alerts |
| **Channels** | Web app (mobile-friendly), reminders and notifications |
| **Behaviour Change** | From occasional manual notes to a quick daily habit supported by smart insights |

**Fit:** The solution removes the effort of tracking and adds predictive insight, which directly addresses the reasons users abandon budgeting.
