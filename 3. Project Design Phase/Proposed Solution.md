## Proposed Solution Template

| S.No | Parameter | Description |
| --- | --- | --- |
| 1 | Problem Statement (Problem to be solved) | People struggle to track daily spending, stay within budget and choose cheaper options because existing tools only record transactions and give no personalised guidance |
| 2 | Idea / Solution Description | PocketSmart AI is a web-based smart budget assistant. Users log income and expenses, an ML model auto-categorises spending, budgets and alerts prevent overspending, and a generative AI assistant provides personalised saving and product recommendations |
| 3 | Novelty / Uniqueness | Combines expense tracking, ML categorisation, budget alerts, goal planning and a conversational GenAI advisor in one simple app; advice is based on the user's own spending data |
| 4 | Social Impact / Customer Satisfaction | Builds financial awareness and saving habits among students and families, reduces money-related stress and encourages responsible spending |
| 5 | Business Model (Revenue Model) | Free basic plan; premium plan with advanced insights and reports; partnerships for verified offers and cost-saving recommendations |
| 6 | Scalability of the Solution | Modular design allows more categories, languages and data sources (bank statements, UPI exports); the cloud database and API layer can scale to more users |
